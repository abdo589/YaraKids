تعديل صفحة Yara Kidsافتح الصفحة

أول مرة بس: اربط لوحة التعديل بـ GitHub

  1. افتح صفحة عمل Token جديد (Fine-grained).
  2. Token name: اكتب yara-kids-admin، وExpiration اختار المدة اللي تناسبك.
  3. Repository access: اختار Only select repositories ثم YaraKids.
  4. Permissions → Repository permissions → Contents: اختار Read and write.
  5. دوس Generate token وانسخ الكود اللي بيبدأ بـ github_pat_ والصقه هنا.

الـ Token بيتحفظ على الجهاز ده بس، ومحدش بيشوفه. ماتبعتهوش لحد.
